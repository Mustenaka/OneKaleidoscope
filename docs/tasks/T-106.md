# T-106：R3 projection 与 LAN transport 合同

> 状态：**active**  
> 里程碑：R3  
> 基线：`main@710d2d9`

## 1. 目标

在写 socket 或 Android UI 前，关闭三处会导致假恢复或越权的合同缺口：

1. projection 使用 canonical stream head，跨 stream 依赖变化时 cursor 不前进；
2. R3 要求 LAN 配对，但现合同把配对/分帧全部留到 R4；
3. 手机没有安全写入 prompt/free-form 正文的入口，且不能提交伪造 Actor 的完整
   `CommandEnvelope`。

本卡交付 UACP `0.3.0` 与 TRANSPORT `0.1.0` 的正式合同，不实现生产 socket 或 UI。

- `docs/REQUIREMENTS.md` §3、§5、§6

## 3. 决策

### 3.1 Projection cursor

- 新增闭合 `ProjectionKey`，把 projection 种类和唯一 scope 合成一个 key；
- `ProjectionEnvelope.cursor` 按 `ProjectionKey` 独立、持久、严格 `+1`；
- 新增 `ProjectionSubscribe` / `ProjectionSubscribeAck` /
  `ProjectionSubscribeOutcome`；
- Android 只接收完整 projection，不接收 canonical `LogRecord` 并重写状态机；
- 当前投影早于保留窗口时返回 `CurrentFollows`，随后发送当前完整 projection；
- cursor ahead、重复、gap、key/payload 错配必须 fail-closed。

### 3.2 可信 mobile command

- 新增 `DeviceId`；`Actor::Human` 绑定可信 `device_id`，显示名留在 transport 设备目录；
- 手机提交 `DeviceCommandRequest { idempotency_key, ttl_ms, body }`，不提交 Actor、
  command_id 或 issued_at；
- hostd 从认证连接注入 Actor、时间与 canonical command ID；
- 同一设备同 key 同摘要为 Duplicate，异摘要为 `IdempotencyConflict`。

### 3.3 敏感正文写入

- 新增独立 `ContentWriteRequest/Response`，不进入 command、durable log 或 projection；
- R3 只接受 ≤64 KiB 的 PlainText / Markdown；host 强制 Sensitive、无 preview，并计算
  digest/ContentId；
- 上传、读取、命令都必须发生在已鉴权加密连接上。

### 3.4 LAN transport

- TRANSPORT 版本独立为 `0.1.0`；
- TLS 1.3、Host pin、一次性短时配对 secret、Android Keystore P-256 设备密钥；
- 重连使用 server nonce + 设备签名，支持持久吊销；
- transport/auth/frame 错误使用独立闭合错误，不伪装成 provider `CanonicalError`；
- R4 relay 复用加密字节流，不要求 R3 实现公网 rendezvous/relay/push。

## 4. 允许修改

- `docs/PROTOCOL.md`、`docs/TRANSPORT.md`
- `docs/adr/0020-*`、`docs/adr/0021-*`
- `crates/kaleido-proto/**`
- UniFFI Kotlin/Swift probe 与合同测试
- 状态/任务索引文档

禁止在本卡实现网络 listener、Android 工程、provider runtime 或 projection journal。

## 5. Definition of Done

- [ ] `PROTOCOL_VERSION == 0.3.0`，只接受 `0.3.x`，拒绝 `0.2.x`；
- [ ] 8 种 `ProjectionKey` 与 payload scope 逐一互验；
- [ ] projection subscribe 的 resume/current/ahead/gap/overflow 路径有合同测试；
- [ ] 远端请求无法声明 Broker/Workflow actor 或伪造 command ID/时间；
- [ ] ContentWrite 大小、kind、digest 和 Sensitive 规则有正负测试；
- [ ] TRANSPORT 0.1 的配对、认证、吊销、限额和日志禁区写成可实现合同；
- [ ] Kotlin 与 Swift 生成 consumer 编译新类型；
- [ ] 至少三处真实变异会让对应测试变红并恢复；
- [ ] `cargo xtask ci` 与三平台 CI 全绿。

## 6. 边界

本卡允许破坏 UACP 0.2 handshake，但不迁移或猜测旧 durable log；本卡没有改变
`StateEffect` 或现有 canonical 对象的持久形状。任何需要改 `StateEffect` 的发现必须另记。
