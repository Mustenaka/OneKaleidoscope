# T-114：UACP QuestionSet 与多答案移动端合同

> 状态：**completed，2026-08-10；共享合同本地总门禁通过，不代表 R5 完成**
> 里程碑：R5 合同前置
> 集成基线：`origin/main@c993d9f9bb115003e2ee69066c233ac47b7c52cc`

## 1. 问题

UACP 0.3 的 `QuestionRequest` 只有一个 prompt、一组单选 option 和一个 free-form；
`AttentionResponse` / `AttentionState::Answered` 也只能保存一个 option 或一段自由文本。
Claude Agent SDK 的公开 `AskUserQuestion` 是非空问题数组，每题有稳定关联、可以单选或多选，
并返回逐题 answers。压扁会丢问题、多选或答案关联，违反能力诚实表达。

## 2. 决策范围

- 提升 UACP pre-1.0 minor 到 `0.5.0`；未发布的 `0.4.x` 与旧 durable/wire 形状均
  fail-loud，不做启发式迁移；同一版本还承载 mandatory
  `AcceptedByRuntime { session_id, acceptance_kind, binding_handle }`，其中 PromptTurn 与
  SessionControl 不得互换；
- `QuestionRequest` 改为非空 `QuestionPrompt` 列表，每题有 Broker `question_key`、敏感 prompt、
  runtime options、`multi_select` 与 `free_form_allowed`；
- `AttentionResponse` 与 `Answered` 保存逐题 `QuestionAnswer`；Approval/WorkflowGate 继续使用顶层
  decision，并拒绝 question answers；QuestionSet 拒绝顶层 decision；
- question keys、option IDs 与 answers 去重；答案恰好覆盖全部问题；单选题拒绝多 option，
  free-form 未允许时拒绝正文，空答案拒绝；
- 同步 PROTOCOL、ADR、proto/state/core、UniFFI、Kotlin/Swift probe、Android UI 与版本握手。

决策见 [ADR-0025](../adr/0025-question-set.md)。
