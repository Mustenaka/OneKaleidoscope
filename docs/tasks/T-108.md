# T-108：Android 局域网纵切

> 状态：queued，前置 T-107  
> 里程碑：R3

## 1. 目标

交付第一个可用的 Android App。用户离开 PC 后，仅用 Android 查看 Codex 项目/会话/实时
活动，发送 prompt 或排队输入，处理 approval/question，并在断线或进程被杀后恢复。

## 2. 工程边界

- `apps/android/core-android`：构建两 ABI Rust `kaleido-core`、生成 UniFFI Kotlin、打 AAR；
- `apps/android/app`：Compose Material 3、Navigation、ViewModel/Flow；
- Kotlin 只负责 UI、生命周期、网络权限、Keystore/安全偏好与扫码输入；
- projection、cursor、重连、命令/能力语义和 content digest 全部来自 Rust core。

最低页面：

1. 配对/已配对 Host；
2. provider → Project 列表；
3. Session 活动/历史列表；
4. Transcript + LiveActivity；
5. InputQueue；
6. Attention Inbox 与 approve/deny/question；
7. Runtime capability / 离线与错误状态。

## 3. 安全与恢复

- P-256 私钥在 Android Keystore 中不可导出；
- endpoint、Host pin、DeviceId 放加密偏好，projection/cursor cache 放 no-backup storage；
- 正文默认不落移动端持久缓存；
- force-stop 后先显示明确标记的离线缓存，再按 cursor 恢复；
- capability 不支持时按钮必须显示原因，不得按 provider 名称隐藏。

## 4. Definition of Done

- [ ] Gradle wrapper、AGP/Compose 版本与依赖全部固定；
- [ ] arm64-v8a 与 x86_64 `.so`、AAR、debug APK 构建通过；
- [ ] lint、JVM tests、API 35 emulator instrumentation 全绿；
- [ ] emulator 真实加载 UniFFI `.so` 并走 callback/async/error；
- [ ] hostd ↔ emulator 真实 TLS 配对、错误 pin/吊销拒绝；
- [ ] Project/Session/Transcript/Live/Queue/Attention 均由真实 projection 渲染；
- [ ] prompt、approve/deny/question、enqueue 至少各覆盖一个支持或诚实 unavailable 路径；
- [ ] force-stop → 冷启 → 离线缓存 → cursor resume 无漏无重；
- [ ] Compose 可访问性、深浅色、窄屏与旋转不丢状态；
- [ ] `cargo xtask ci`、三平台 CI、Android CI 全绿；
- [ ] 实体 arm64 Android 的 LAN/Wi-Fi、OEM 后台与 hardware-backed Keystore 结果单独登记，
      没有设备时不得伪报通过。

## 5. R3 最终门禁

真实 Codex + hostd + Android：用户离开 PC 后只用 Android 完成一次实时查看、一次人工
应答、一次 prompt/排队或 steer 意图，并在断线后恢复。若实体设备门禁尚未执行，T-108
只能标记为 emulator implementation complete，R3 仍未最终通过。
