# T-116：R6 跨 Agent 工作流与 Android WorkflowBoard

> 状态：**active；任务定义已建立，实现尚未启动**
> 里程碑：R6
> 集成基线：`origin/main@eefe1340a6ba36163455497a98db31b455b721c1`（PR #12 merge）

## 1. 用户可见目标

用户在 PC 上建立一条真实的“Claude 规划 → Codex 执行 → Claude 审核”工作流，随后离开 PC，
只用 Android 查看步骤、关联会话、阻塞与产物，并完成一次人工 gate、一次审核返工和再次推进。
PC/手机网络切换、App 冷启或 hostd 重启后，工作流状态、队列、等待项与投影 cursor 不丢、不重、
不回退。

## 2. 独立性与边界

- 本卡可与 [T-111](T-111.md)、[T-113](T-113.md)、[T-115](T-115.md) 并行推进；开卡或推进
  R6 不会把 OpenCode 漂移、三 Provider 实体总格或 R4 公网 release gate 标为通过。
- 首条产品纵切使用真实 Claude 与 Codex structured runtime；OpenCode 不作为 R6 引擎起步前置，
  但实现不得按 provider 名称分支。`RuntimeSelector.required`、runtime capability 与明确 assignment
  才是调度依据。
- 复用现有 UACP Workflow/Step/Artifact/Attention/Command/WorkflowBoard 合同；如实现发现协议语义
  缺口，必须在同一提交同步 ADR、`PROTOCOL.md`、Rust 类型、UniFFI consumer 与会失败测试。
- Agent 数据继续只来自公开结构化协议。禁止 PTY/TUI/ANSI、抓屏/OCR、轮询 transcript，禁止用
  mock/fixture replay 冒充真实最终纵切。
- Artifact、worktree 与返工原因只通过正确 sensitivity 的 `ContentRef` 交接；canonical log、projection、
  tracing、push 与 relay 不得出现代码、diff、计划正文、工具参数、凭据或完整路径。

## 3. 实现纵切

1. 在 `kaleido-state` / hostd 中持久化 Workflow DAG、Step audit、attempt、Artifact 引用、human gate
   与关联 Session；重启后从 durable log 精确恢复并重建 WorkflowBoard projection。
2. 实现依赖、capability 与 human gate 驱动的调度：未满足条件时保持可解释的 blocker，只有结构化
   runtime receipt/turn/artifact/human answer 才推进状态；不能把 enqueue、启动请求或空历史冒充完成。
3. 闭合 Plan → Implement → Review 的显式 Artifact 交接，以及 Advance、Retry、Rework、Skip、Cancel、
   Reassign 的允许转移、幂等、拒绝路径、checked attempt 与审计记录。
4. Android 增加 provider-neutral WorkflowBoard，展示 DAG、步骤状态、blocker、assignment、Artifact、
   human gate 与关联会话跳转；移动端只发送现有可信命令，不能伪造 Actor、时间、ID 或完成状态。
5. 以真实 Claude/Codex runtime 跑通创建、计划、执行、审核、返工、再执行与审核完成；在手机处理
   一次权限请求、一次问题、一次 steer 或排队消息和一次审核返工。

## 4. Definition of Done

- [ ] DAG cycle、跨 workflow dependency、错误 project binding、缺失 capability、未回答 human gate、
      非法 state transition、attempt overflow 与重复/冲突移动幂等键全部 fail-closed；
- [ ] hostd 崩溃、provider 退出、手机断线、App 冷启与网络切换后，WorkflowBoard、关联 Session、
      Attention、InputQueue 与逐 key cursor 精确恢复，无漏、无重、无回退；
- [ ] Artifact producer/consumer、kind、sensitivity、生命周期与访问授权均有拒绝路径测试，敏感正文
      不进入 canonical JSON、projection、日志、push 或 relay；
- [ ] Android 可查看步骤与关联会话，并执行 Advance/Retry/Rework/Skip/Cancel/Reassign；UI 不按
      provider 名称分支，不隐藏 unsupported/not-verified/upstream-blocked capability；
- [ ] 至少对 dependency、receipt-driven completion、artifact scope、human gate、attempt、cursor resume
      六类关键守卫实际做变异验证，测试变红后恢复；
- [ ] 完整 `cargo xtask ci`、Windows/macOS/Linux CI、Android CI 全绿并链接 exact commit runs；
- [ ] 真实 Claude 规划 → Codex 执行 → Claude 审核/返工纵切由 Android 独立推进完成，证据来自同一
      clean candidate；届时再建立 `docs/gates/T-116-evidence.md`，不提前创建空白通过记录。
