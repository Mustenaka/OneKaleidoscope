# T-107：hostd LAN Broker 与 Rust mobile core

> 状态：**implementation complete，等待新 SHA 三平台 CI**
> 里程碑：R3

## 1. 目标

实现 PC hostd ↔ Rust mobile core 的生产纵切：安全配对、projection 订阅/重放、敏感
ContentWrite/Read、可信命令入口、持续 Codex runtime 和冷启动恢复。Android UI 不在本卡。

## 2. 交付面

1. `kaleido-state`
   - `ProjectIndex` builder；
   - 持久 projection journal、每 key 独立 cursor、显式 fanout matrix；
   - resume window、CurrentFollows、gap/ahead/overflow；
   - 持久 command request digest/outbox，修复 crash window 与异体 key 冲突。
2. `kaleido-transport`
   - TLS 1.3 listener/client、pin 验证、长度/连接/订阅限额；
   - 一次性 pairing、P-256 challenge auth、设备目录与吊销；
   - 结构化 request correlation，绝不记录 secret/body/path。
3. `kaleido-hostd`
   - 常驻 Broker、runtime supervisor、projection subscription hub；
   - ContentWrite/Read、可信 DeviceCommand gateway；
   - SubmitPrompt、RespondAttention、EnqueueInput 的真实路由；
   - listener 成功后才发布 `LanDirect`，关闭后恢复 Offline。
4. `kaleido-core`
   - product `MobileClient` / subscription handle / callbacks；
   - pair/connect/reconnect/subscribe/submit/read content；
   - projection/cursor cache 与 projection version 失配刷新；
   - device signer 通过 UniFFI callback 使用平台 Keystore。

## 3. 禁止

- 不把 provider JSON-RPC 或 canonical reducer 搬进 Kotlin；
- 不开放明文或无鉴权业务端口；
- 不用 projection payload 自己猜 cursor；
- 不把 AcceptedLocally 显示成 runtime 已接收；
- 不实现 R4 relay/push，也不修改其他 provider。

## 4. Definition of Done

- [x] 基于三份真实 Codex fixture 构建 7 类 R3 projection，ProjectIndex 计数随子状态变化；
- [x] 每种 effect 的 fanout 有逐项测试，未改变 view 不分配新 projection cursor；
- [x] 断线期间 host/project/session 多处变化后按 cursor 精确恢复，无漏无重；
- [x] pairing 成功、错误 pin、错误/过期/重复 secret、重放签名、吊销均有测试；
- [x] 未鉴权连接无法 subscribe、content 或 command；
- [x] 同 idempotency key 异摘要拒绝，崩溃恢复不重复下发 runtime；
- [x] prompt、approval、enqueue 通过真实 canonical 路径，ack 与 projection 顺序正确；
- [x] prompt/body/secret/private key/完整路径不进入 tracing、日志或 transport metadata；
- [x] `kaleido-core` Android `aarch64`、`x86_64` 均交叉编译；

## 5. 真实验收

以本机已登录 Codex 启动常驻 hostd；Rust mobile core 通过 LAN loopback 完成配对、订阅、
发送 prompt、处理一次 approval 或明确无等待项、断开后恢复到相同 projection cursor/state。
