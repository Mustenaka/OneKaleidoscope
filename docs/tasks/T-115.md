## 1. 目标

只验证已经合并的 R4 实现，不继续增加功能。使用自有 Ubuntu、家宽 PC、真实 FCM 凭据和
实体 arm64 Android，在 Wi-Fi/VPN 关闭的蜂窝网络上完成公网纵切。自动化、模拟器、LAN、
`adb reverse`、公共 relay 或 mock 都不能替代本卡。

## 2. 前置

- 从待验收的同一 clean `main` commit 构建 Ubuntu relay、PC hostd 与 Android App；
- Ubuntu 使用自有 DNS/ACME、owner-only registry/identity/FCM ADC，开放部署文档指定端口；
- PC 只向外连接；手机为单一已授权实体 arm64 设备；
- 先运行 `./scripts/t110-physical-preflight.ps1`，保留私有 JSON，不在仓库记录 serial、FID、
  endpoint、token、用户名或完整路径。

## 3. 必须完成的真实路径

1. 记录自有 Ubuntu、PC、Android 与网络拓扑的脱敏版本信息；
2. 真实 P2P 成功，并强制 P2P 失败后在有界时间内转为 authenticated `Relayed`；
3. 七类真实 Codex projection 保持可见，完成一次真实 prompt/queued input 与结构化 Attention；
4. App 后台由真实 data-only FCM 唤醒；蜂窝↔Wi-Fi 切换与进程冷启精确恢复逐 key cursor；
5. PC 真离线时手机显示带时间的 `Offline`，恢复后不重放命令；
6. 吊销后 LAN、P2P、relay 与后续 push 全部拒绝同一设备；
7. Ubuntu relay 日志、抓包和进程内诊断扫描业务 canary，结果零命中。

## 4. 完成条件

- evidence 的 candidate、三端版本、路径、耗时、cursor 与吊销结果来自同一 commit；
