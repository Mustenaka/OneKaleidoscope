# T-109：实体 arm64 Android 最终门禁

> 状态：已完成，2026-08-10
> 里程碑：R3

## 1. 目标

在非模拟器 arm64 Android 上闭合 R3 最终门禁。设备必须通过真实 Wi-Fi 连接 hostd，
不得使用 `adb reverse` 或伪造 projection；人工应答必须来自真实 Codex app-server 的
结构化 Attention。

## 2. 产出

- `scripts/android-physical-arm64-gate.ps1`：单命令执行本地门禁、APK 构建/安装与实体阶段；
- `physical_gate_host`：本地 operator-only 配对/吊销 harness，不把一次性 URI 写入 tracing；
- 实体设备 hardware-backed P-256、wrong pin、七投影、命令、审批、后台、冷启与吊销测试；
- [T-109 门禁结果](../gates/T-109-result.md)。

## 3. Definition of Done

- [x] 仅接受恰好一台 authorized、非 qemu、支持 `arm64-v8a` 的设备；
- [x] AndroidKeyStore P-256 私钥不可导出，`KeyInfo` 为 TEE 或 StrongBox；
- [x] PC 与手机通过真实 LAN IP 通信，错误 SPKI pin 被拒绝且不落凭据；
- [x] 七类 R3 projection 均为 Live，Android 提交 prompt；
- [x] Codex read-only scratch 项目产生真实 file-change approval，Android 选择 decline，
      `editable.txt` 保持 `ORIGINAL`；
- [x] 90 秒 OEM 后台后显式重连，七投影恢复 Live；
- [x] 外部 force-stop 后从最后缓存 cursor 冷启，重连 cursor 不回退；
- [x] durable revoke 后凭据认证进入 Revoked；
- [x] `cargo xtask ci`、双 ABI Android 构建、PowerShell 5.1 兼容检查通过；
- [x] hardware-backed 判断实际变异为 false 时实体测试变红，恢复后同设备通过。

## 4. 边界

- 不修改 UACP/TRANSPORT wire、schema 或 fixture；
- production `lan run` 继续默认 `workspace-write`，门禁 harness 显式使用 `read-only`；
- 深度 device-idle 未取得 OEM 权限时诚实记录为 false，不伪报；
- 公网 relay、推送、蜂窝切换与活进程树终止属于 R4。
