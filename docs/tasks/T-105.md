# T-105: 审查 Codex 0.147.0 必需面漂移并恢复 Schema drift 门禁

> 状态：**technical gates passed; status-index sync remains in concurrent documentation work**
> 日期：2026-08-09
> 里程碑：R3 开工前的上游兼容性维护；优先于 T-103
> 主管：Codex（项目负责人本轮明确授权）。实现方：Codex。
> 基线：`main@75f3588`；目标上游：`@openai/codex@0.147.0`

一句话目标：逐项审查 Codex `0.147.0` 引起的 58 处 required-surface 漂移，在真实
app-server 证据证明 canonical 语义兼容后更新原样快照与支持证据，使固定版本和当前 latest
的 Schema drift 门禁恢复为绿色。

本卡不是“刷新快照让 CI 变绿”。required surface、钉定路径或真实 wire 语义有任何不兼容，
必须显式修复或停下来走 ADR；不得删除条目、放宽比较器或改写协议来掩盖漂移。

---

## 1. 已知事实

- GitHub Actions `Schema drift` run `31293304076` 在 Codex `0.147.0` 上报告
  `58` 处 in-surface drift，并按合同 exit `1`。
- 同一 run 的 OpenCode `1.18.15` 只有版本警告；日志列出的 58 处均属于 Codex required
  surface。OpenCode 的 supported range 仍归 D-B11 / R5，本卡不宣称解决。
- 常规三平台 CI 在 `75f3588` 上全绿；本地 `cargo xtask ci` 于 2026-08-09 exit `0`。
- Codex adapter 按 ADR-0012 使用 41 条钉定 JSON Pointer；不生成也不手写上游类型。

## 2. 前置合同

- `docs/UPSTREAM.md` 的 Upgrade and compatibility process 与退出码合同；
- ADR-0008：版本不一致是数据，面内漂移必须人工审查；
- ADR-0012：Codex 只按钉定路径解码，路径表与 required surface 双向守卫；
- `schemas/required-surface.toml`、`crates/kaleido-adapter-codex/src/surface.rs`；
- T-100 三份真实 fixture 与 T-100/T-102 门禁证据。

## 3. 实施要求

### 3.1 逐项漂移审查

把 58 处漂移按 required-surface entry 分组，至少区分：

1. 实际被 41 条钉定路径读取的 wire 形状；
2. required type 的传递 `$ref` 闭包变化；
3. 新增可选字段或描述文本；
4. 删除、重命名、必填集合或枚举变化。

审查结论写入 `docs/gates/T-105-evidence.md`，不得只贴总数。每组必须说明是否影响现有
decoder/reducer/canonical 语义，并给出 schema 路径或真实报文证据。

### 3.2 真实 Codex 0.147.0 证据

- 在仓库外的临时 npm prefix 安装精确 `@openai/codex@0.147.0`，不得覆盖用户全局
  Codex `0.146.0`；
- 用该精确可执行文件生成原样 schema；
- 对 41 条钉定路径运行快照可解析性测试；
- 通过结构化 app-server JSON-RPC 跑至少一次真实 simple turn；若兼容性结论涉及审批回复，
  再在临时项目中录制真实 file-change approval；
- 契约 fixture 若新增，必须来自上述真实录制，保留原始 JSONL，不得手工构造；现有 fixture
  一律不修改。

### 3.3 兼容时的更新

只有 3.1/3.2 证明兼容后才允许：

- 通过 `cargo xtask schema refresh` 获取原样上游快照，不手工编辑 `schemas/codex/**`；
- 执行 refresh 时把 OpenCode 固定为已提交的 `1.18.8`，ACP 固定在现有不可变提交，确保本卡
  不夹带 D-B11；
- 更新 `schemas/VERSIONS.md`、`docs/UPSTREAM.md` 与一份去重后的
  `schemas/surface-history.jsonl` 观察记录；
- `schemas/required-surface.toml` 只允许更新 Codex `supported_range`，禁止删除或改小 entry；
- supported range 只能覆盖本卡实际取得 runtime/fixture 证据的版本。

若 wire 路径确实变化但 canonical 语义不变，可窄改 `kaleido-adapter-codex` 的钉定表与
decoder，并增加错误路径测试。若需要改变 `kaleido-proto` 或 `PROTOCOL.md`，立即阻塞并另走 ADR。

下一阶段为 T-103 ADR 审批。OpenCode D-B11 保持未解决。
