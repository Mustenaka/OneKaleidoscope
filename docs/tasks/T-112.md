## 1. 用户可见目标

`kaleido-hostd` 通过公开 Claude Agent SDK 创建并拥有 Claude Code 会话，使现有移动端投影
真实显示会话、历史、流式 turn、工具生命周期、permissions/问题、prompt、interrupt、队列与
断线恢复。本卡只声明 SDK managed session；不得把它冒充独立原生 Claude CLI/GUI 的第三方
live attach。

开卡时 npm current `@anthropic-ai/claude-agent-sdk` 为 `0.3.226`。实现必须钉定并记录 SDK 与
实际运行二进制版本，不按版本号硬编码功能。

## 2. 上游与桥接合同

- SDK 侧使用官方 TypeScript 类型和公开 API；进程桥只把 SDK typed message 转成本项目自有、
  闭合、版本化的内部 frame，Rust 不手写 Claude 上游 DTO；
- package 与 lockfile 精确钉定，bridge strict typecheck 是门禁；hostd 不全局安装 npm 包；
- raw Claude session/message/tool/request ID 只进入 adapter 私有绑定存储；
- Agent SDK managed session、ACP 路径与原生 CLI/GUI 必须在 ownership/history/live/evidence 中区分；
- provider 映射同步生效 ADR、`PROTOCOL.md` 附录与真实 fixture。

SDK `AskUserQuestion` 是多问题集合且单题可多选，必须按 [T-114](T-114.md) 的共享
QuestionSet 合同逐题映射。bridge/provisional Session 决策见
[ADR-0027](../adr/0027-claude-sdk-sidecar-provisional-session.md)。

## 3. 交付

1. `kaleido-adapter-claude`：SDK bridge lifecycle、typed frame decode、session create/resume/list、
   streaming message/tool/permission、prompt、interrupt 与 close；
2. reducer：映射现有 canonical state；permissions/questions 生成可回答 Attention；本地与 external
   answer provenance 不混淆；
3. 能力：只由 SDK option/callback 和实际 runtime acceptance 证明；缺证据的动作保持
   `NotVerified`、`Unsupported` 或 `UpstreamBlocked`；
4. 恢复：hostd/bridge 重启后用 SDK 公开 resume/list 恢复，canonical state 与 projection cursor
   收敛且命令不重复提交；
5. 真实证据：隔离 toy project 记录 SDK managed session 的 successful streaming turn、tool、
   permission allow/deny、question、interrupt 与 resume；未触发项如实保留空缺。
